# 素材获取

素材优先级：**产品一手素材 > AI 生成 > 网络素材**。一手素材（真实界面、真实作品、真实数据）是说服力的来源，AI 生成主要用来做氛围、背景、角色和 logo 渲染。

所有素材在 `调研笔记.md` 里登记：文件 → 来源（路径/URL）→ 用在哪个场景。

---

## 1. 产品一手素材

### 本地仓库 / 文档
- 先读 README、目录结构、各章节标题，统计真实数字（文章数、图片数、字数、模块数）。统计方法和结果写进调研笔记，片中数字只用统计出来的。
- 批量抓文档配图，按文档出联系表逐篇挑：

```bash
python3 scripts/images.py grab "<仓库路径>/20 项目实战" "<仓库路径>/15 模型动态" -o /tmp/imgs
python3 scripts/images.py sheet /tmp/imgs            # 每篇一张 _sheet_<组号>.jpg，逐张看
python3 scripts/images.py crop out/pick.jpg /tmp/imgs/ab12c_03.png /tmp/imgs/9f0e1_11.png
python3 scripts/images.py prepare /tmp/imgs/ab12c_03.png public/works/hotpulse.jpg
```

- **核对每张图的上下文**：图前后的段落在说什么？是本产品做的，还是官方演示 / 对比对象 / 参考案例？不确定就不用。
- 截图常见问题：一张图里是多屏拼接（手机界面三连屏）、带标注红框、裁切了一半。选「成品效果图」，不选「操作过程图」。

### 官网 / 线上产品
- `firecrawl scrape` 拿文案和结构，**同时把页面里所有作品图的 URL 抽出来**。帖子、文档、课程介绍页往往有大量高清实拍图（编程导航的「项目学习建议」帖子里有 38 张 2000~4400px 的项目截图），先盘点再决定要不要登录。
- 真实界面截图可以分层重建：把卡片、按钮、列表用 React 重新画出来，比静态截图能做更多动画（Vibe 的「小鱼记账」应用就是这样逐块长出来的）。但重建是在截图基础上的**加法**，不能替代截图本身。

### 真实界面截图（4K 可用）
- **首选 `scripts/shot.py`**（Playwright，任何 AI 工具里都能用）：`python3 scripts/shot.py <网址> <名字> --scroll 0 1400` 按 1920×1080 @2x 截图，得到 3840×2160 的 `out/shots/<名字>-<序号>.jpg`。`--hide` 传 CSS 选择器隐藏横幅和悬浮条，`--eval` 传一段 JS 做更细的清理，`--tall 4200 --scale 1.25` 截整页长图。
- **需要登录**：先跑 `python3 scripts/shot.py --login <网址>`（后台运行），它会弹出一个有界面的浏览器窗口；请用户在**这个窗口**里登录（扫码等），登录完关掉窗口。登录状态存在 `out/.browser-profile/`，之后这个工程里的 `shot.py` 截图都带着它。请用户登录时**说清楚是哪个窗口**：用户常会主动说「我在内置浏览器里帮你登录」，可内置浏览器截不了高清图。
- **也可以用 Chrome DevTools MCP**（如果你的 AI 工具装了）：`new_page` 打开 → `emulate` 设 `viewport: "1920x1080x2"` → `evaluate_script` 清理页面 → `take_screenshot`（`format: "jpeg", quality: 92, filePath: ...`），同样得到 3840×2160。
- **不要用 AI 工具的内置浏览器截产品图**（如 Cursor 内置浏览器；pi 没有内置浏览器）：它的截图最多只有窗口宽度（约 900px、1 倍像素）；一旦模拟更高分辨率或更高像素密度，截出来会变成重复平铺的图。它只适合给用户看效果。
- **用户已经在内置浏览器里登录了**：不用让用户再登一次，改用「快照 + 本地重渲染」。用 `browser_cdp` 的 `Runtime.evaluate` 执行 `scripts/snapshot.js`（`awaitPromise: true`、`returnByValue: true`），它会滚完页面触发懒加载、内联全部样式，返回自包含的 HTML；响应太大会存成文件，把那个文件交给 `python3 scripts/snapshot.py <文件> <名字> --scroll 0 1400`，在本地 Chromium 里按 1920×1080 @2x 渲染出 3840×2160 截图，默认隐藏右上角账号头像。长页面加 `--tall 4200 --scale 1.25`。图片地址是线上的，渲染时需要联网，站点有防盗链时脚本会带上原站 Referer。鱼皮 AI 导航的知识库教程（登录才能看全文）就是这样拿到的。
- **截图超时**（DevTools MCP）：用户登录时切换了窗口，Chrome 会停止出画面，`take_screenshot` 一直超时。先 `select_page` 并传 `bringToFront: true`，再截。
- **清理页面**：截图前隐藏活动横幅（`img[alt*=广告]`、含「特惠 / 续费」字样的整行横幅）、右侧悬浮工具条、底部悬浮条；滚动到要展示的区域再截。
- **截哪些**：首页、每个功能段落对应的真实页面、会员专属内容（登录后）、作品/项目详情、评价/成绩页。想做滚动效果就截同一页的上下几屏，或截整页长图。
- **展示「有很多」的功能段落，截列表 / 汇总页，不截单个详情页**：编程导航第二版的学习路线站用了「Java 学习路线」详情页，用户反馈「应该展示出学习路线列表页面」。数量是卖点时（100+ 条路线、30 套项目），就让观众看到那份长长的列表在滚动。
- **截整页长图**：很多站点的内容区是页面内部独立滚动的（`document.body.scrollHeight` 等于视口高度），`fullPage` 截不到。做法是把视口临时拉高：`shot.py --tall 3000`，或 DevTools 里 `emulate` 设 `viewport: "1920x3000x2"`（截完改回 `1920x1080x2`），得到 3840×6000。再裁出只有列表的那一栏（字更大），视频里用模板的 `src/components/BrowserFrame.tsx` 在窗口内滚动（`ratio` 填原图宽 / 高，`scroll` 0~1）。
- **截图放进画面时必须保持原比例**：模板的 `src/index.css` 已经取消了 Tailwind 给 `img` 加的 `max-width: 100%`。鱼皮 AI 导航的工程是旧模板，浏览器窗口把截图放大 1.12~1.3 倍时，图片宽度被压回窗口宽、高度没变，所有截图都被横向压窄，用户一眼就看出来了。自己写图片容器时，宽高都从原图比例算，不要只写一边再靠 `max-width` 兜底。
- 截图放 `public/shots/`，项目图放 `public/works/`；同屏图片多的场景（图片墙）另外准备 ≤ 800px 的缩略图。

### 社交平台上的案例（X / 推特）
没有官方素材、案例散落在网友帖子里时（新模型灰度、刚出圈的工具）：

- **找原帖**：二手报道（新智元、量子位等）只当线索，顺着文末「参考链接」和截图里的用户名追到原帖。firecrawl 抓 `x.com/<用户>` 主页和单条帖子能拿到正文和回复串（作品常在回复里）。找不到原帖的案例一律不用。
- **下载原始素材**：`python3 scripts/xgrab.py <推文id...>` 走 fxtwitter 公共接口，不用登录，拿到原图（`name=orig`，常见 3000~4000px）和作者上传的原视频（常见 1920×1080），被引用 / 被回复的帖子会顺带抓一层；`--index` 汇总作者、时间、点赞和正文。
- **截推文本身**：X 的帖子页不登录也能打开。按 `1920x1080x2` 打开（`shot.py` 的 `--hide`、`--eval` 或 DevTools）→ 隐藏 `[data-testid=BottomBar]`、`[data-testid=sidebarColumn]`、`header[role=banner]` 和含「继续前往 / 扫码 / 查看所有回复」的固定定位层 → 读 `article` 的 `getBoundingClientRect()` → 截图后按矩形 ×2 裁出主帖。帖子超过一屏时把视口临时拉高。
- **网络**：国内网络下 `pbs.twimg.com`（图片）会被重置连接，`video.twimg.com` 通常能连。`curl` 不读 macOS 系统代理，`xgrab.py` 已自动处理；自己写命令时先查代理端口（macOS `scutil --proxy`，其他系统看代理软件设置），再 `export HTTPS_PROXY=http://127.0.0.1:<端口>`。
- **claude.ai 等站点的分享页**有 Cloudflare 人机验证，自动化打不开；用作者上传的视频代替，在调研笔记里写明。
- **核验归属**：作者原话里有没有说是这个产品 / 这个版本做的？同一作品被多人转发（宝玉、indigo 都转了超人动画）只署原作者；作者自己没说清是哪个模型做的（「猜猜哪个是 5.5」）就不用。点赞数是会涨的，交付前重抓一次 `meta.json` 更新。
- **署名**：每个案例画面上标 `@作者 · 日期`，片尾列全部出处。

### 数据
- GitHub：`gh api repos/<owner>/<repo> --jq '.stargazers_count'`。
- 其它平台数据（粉丝数、用户数）以用户给出或官方公开页面为准，写明出处。

## 2. 图标与 logo

```bash
npm pack simple-icons && tar xzf simple-icons-*.tgz            # package/icons/<slug>.svg，单色，渲染时自己上色
npm pack @lobehub/icons-static-svg && tar xzf lobehub-*.tgz    # AI 产品图标全（Claude Code、Codex、Cursor、Trae…），有 -color 彩色版
```

- simple-icons 已移除部分品牌（如 OpenAI），缺的去 LobeHub 找。
- 下载后渲染一张图标墙核对：名字对不对、颜色对不对、深色背景上看得见吗（单色黑图标在深色背景要 `filter: invert(1)`）。
- 产品自己的 logo 从仓库或官网拿原图；需要 3D / 玻璃质感版时用生图工具以原 logo 为参考渲染。

## 3. AI 生成图片

用途：风格样帧、氛围背景、角色、3D logo、场景插画。用 AI 工具自带的生图能力（Cursor 的 `GenerateImage`、Codex 的图像生成等；pi 本身不带生图，装了生图 MCP / 扩展才用）。没有生图工具时，背景和装饰用代码画（渐变、SVG、`@remotion/noise`），角色类风格改用 emoji / SVG 角色，或请用户提供插画素材。

- prompt 写清：画幅（16:9 / 9:16）、风格方向的关键词、光线、构图、**留出放文字的负空间**、不要出现任何文字（文字统一在代码里排）。
- 角色类（Q 版、吉祥物）：先出主形象并定稿，之后每张都以它为参考图，只改表情/动作，保证是同一个角色。
- 生成图约 1280×720，做全屏背景时配合颗粒、景深或轻微模糊可以掩盖分辨率；需要锐利的主体（logo、字）用矢量或代码绘制。

## 4. 字体

- 中文正文：苹方（macOS 自带，`fonts.json` 里写 `system:PingFang#序号`，Regular=3 / Medium=7 / Semibold=11 / Light=15）。模板默认写成 `苹方|微软雅黑|Noto Sans CJK` 三选一，Windows、Linux 上会自动换成后两个；成片要在不同电脑上渲染出完全一样的字形时，把字体文件放进 `fonts-src/` 再引用。
- 中文标题按风格选，免费可商用、能从 npm 直接拿的：
  - 阿里妈妈数黑体：`npm pack @fontpkg/alimama-shu-hei-ti`（几何、科技感）
  - 得意黑：`npm pack @chinese-fonts/dyh`（斜体、年轻）
  - 其它（站酷快乐体、Zpix 像素、霞鹜文楷手写感等）按风格搜 npm 或官方仓库
- 字体文件放 `fonts-src/`，在 `fonts.json` 登记，`npm run fonts` 子集化。脚本会报告**缺字**，缺字就换字体或改文案。
- 西文可用 `@remotion/google-fonts`（如 Geist / Geist Mono）在 `src/lib/fonts.ts` 里静态导入。
- 选之前用 Pillow 把片中真实标题渲染出来对比几款，再定。

## 5. 配乐与音效

- **ElevenLabs**（用户提供 key 时优先）：按分镜作曲、按画面定制音效、v4 旁白，都用 `scripts/elevenlabs.py`。方法见 `音乐与卡点.md` 第 6 节和 `配音.md`。付费套餐可商用；免费套餐只能用音效，而且不能商用。
- **Mixkit**（可商用、免署名）：配乐和音效都用 `scripts/music.py`：

```bash
python3 scripts/music.py search music cinematic trailer electronic uplifting   # 列标题/id/时长
python3 scripts/music.py search sfx whoosh impact riser typing glitch click
python3 scripts/music.py get music 726 614 -o /tmp/music
python3 scripts/music.py get sfx 790 2531 1486 -o audio-src
```

  常用音效分类：`whoosh` `impact` `riser` `typing` `click` `glitch` `transition` `swoosh` `pop` `notification` `heartbeat` `bell`。
- **Remotion 托管音效**：`https://remotion.media/<名字>.wav`（如 `whoosh.wav`、`mouse-click.wav`）。
- 合成音效（`audiolib.py`）：低频冲击 `sub_boom`、提示音 `blip`、卡片滑动 `flick`、环境底噪 `room_tone`。**不要用合成的持续音调（drone）垫在音乐下面**，容易和曲子调性打架（Vibe 第一版开场「音乐怪」就是这个原因）。
- 用户如果要求用热门歌曲且自担风险，按用户说的来，并记进需求确认。

## 6. 视频素材

- 产品演示录屏：优先用户提供；没有时可以用浏览器工具操作线上产品录屏，或用 React 重建界面做动画（更清晰、可控）。
- 网络视频片段只在用户明确授权的前提下使用。
