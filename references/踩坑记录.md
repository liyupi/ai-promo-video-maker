# 踩坑记录

每条都是真实踩过的。遇到怪问题先查这里；新踩的坑追加到对应分类。

## 内容与创意

| 坑 | 表现 | 解决 |
|---|---|---|
| 节奏太快 | 用户反馈「观众反应不过来」：快切 0.45 秒、信息场景 3.6 秒 | 按 AGENTS.md 的节奏底线；放慢时优先放慢信息密集段，视觉冲击段可以保持 |
| 网址只在片尾出现，网页版还被隐藏 | 用户说「全片没有一个地方放完整网址」 | 最高潮段落放一次醒目的网址（地址栏样式），片尾再放一次；网页版结尾不要把网址藏掉 |
| 冒用非本产品的作品 | 最好看的截图是模型厂商的官方演示 | 看图片上下文核对归属；不确定就不用 |
| 挑图只看每篇前几张 | 最好的效果图在文章「功能演示」部分被漏掉 | 抓全量配图，按文档出联系表逐篇挑 |
| 同一作品出现两次 | 两张相似截图被当成两个作品 | 每个作品只留一张最有代表性的 |
| 介绍产品本身太少 | 作者背书和数字占太多，看不出产品全貌 | 用模块全景、真实页面、章节/功能清单体现丰富度；背书一笔带过 |
| 风格滑回默认 | 每次都做成深色蓝紫科技风 | 风格必须经需求问询确认，样帧给用户看过 |
| 用户说的产品还没发布 | 「给新出的 Fable 5.5 做宣传片」，官网最新只有 5.1，5.5 只是当天的灰度传闻 | 预调研第一步查官方新闻页；没有官方来源就先问定位（见 `需求问询.md` 第零步），不要把传闻当事实写进片子 |
| 谜语式开场 | 「标着 Fable 5.1，答的却不是它？」懂行的人觉得妙，用户说「让人摸不到头脑，没把故事讲清楚」 | 第一句先用大白话交代事件，再讲怎么回事；梗和人名配解释卡；交付前做外行复述测试 |
| 给案例加了原帖没有的定语 | 写了「纯 SVG 代码绘制」「带配乐的短片」「七种画风」，原帖都没说 | 说明文字只用原帖 / 官方原话里有的信息；审图清单里逐条对照 |
| 二手报道的案例找不到原帖 | 水母对比、鹈鹕骑车、七大奇迹只出现在新智元转述里 | 找不到原帖就删；转发的同一作品只署原作者；二手报道的日期常是北京时间，以官方为准 |
| 文档网址 404 被当成泄露证据 | 社区传 `.../models/fable-5-5/overview` 返回 404 | 任何不存在的路径都会 404，不能证明什么；不放进片子 |
| 把分页页码当成收录总数 | firecrawl 问答说「Skills 收录 341 个」，其实 341 是分页最后一页的页码（实际 8169 个） | 列表页的数字先看上下文；总数用「(末页页码 - 1) × 每页条数 + 末页条数」自己数，Playwright 点到 `?current=<末页>` 核实 |

## 视觉

| 坑 | 表现 | 解决 |
|---|---|---|
| 文字和背景同色系 | 浅蓝背景上的蓝青渐变字、日出光效上的白字 | 加深文字颜色 + 白色/黑色光晕（`filter: drop-shadow`），或压暗文字区域背景 |
| 窄卡片横排标题折行 | 「五大核心心 / 法」 | 竖排（`writing-mode: vertical-rl` + `textOrientation: upright` + `whiteSpace: nowrap`）或加宽卡片、减少卡片数 |
| 扇形/叠放卡片互相遮挡 | 后一张盖住前一张的字 | 减少重叠或让文字区在可见部分；审图专门看 |
| 小图放大 | 180×208 的截图放进 4K 画面发糊 | `check_assets.py` 会提醒；换图 |
| 字体普通 | 用户说「不够科技感」 | 标题换有性格的字体（按风格选），正文保留苹方 |
| UI 数值溢出 | 统计卡片副标题、图例换行溢出 | 给定宽度 + `whiteSpace: nowrap`，审图时专门看小字 |
| 同色元素叠在同色文字后面 | 品牌蓝标语压在品牌蓝小图标上，字像被挖掉一块 | 审图时专门看「运动元素 × 文字」的交叠，挪开其中一个 |
| 等距地图里地标挡住路线 | 地标塔盖住路线拐角，光标像贴在楼面上 | 地标放在「前角就是路线拐角」的街区，路线和光标永远在楼前 |
| 英文大标题被挤到第二行 | 「Claude Fable 5.5」196px 超出档案夹宽度，「5.5」掉到下一行压住印章 | 大标题一律 `whiteSpace: nowrap`，按最宽字符估宽度（ShuHei 拉丁字母约 0.6em）；截图确认 |
| 蒙太奇的字压在亮画面上看不清 | 报纸、彩色玻璃这类亮镜头上，靠阴影的白字糊掉 | 视频上的文字都加深色底条（`rgba(10,9,8,0.82)`），顶部渐变压暗加深 |
| 截图素材分辨率太低 | 课程封面 200×200、项目封面 646×300，放大到 4K 发糊 | 卡片、图标用代码重绘（文字取自封面原文），只把尺寸够的真实图（≥ 显示宽度 ×2）直接放进画面 |
| 手绘笔画变成一段一段的虚线 | 老鱼简历：红笔下划线、大红叉用 `viewBox="0 0 100 100"` + `preserveAspectRatio="none"` + `vectorEffect="non-scaling-stroke"` 画，`strokeDasharray` 按 viewBox 里的路径长度算，屏幕上实际长度大好几倍，描到底也断成几截 | 做「笔画描出来」的动画时，先把路径坐标换算成像素再用 `getLength` 量长度，不要靠 viewBox 拉伸 |
| 所有网页截图被横向压窄 | 鱼皮 AI 导航：浏览器窗口把截图放大 1.12~1.3 倍，用户说「比例都不对，怎么感觉都被压窄了」。Tailwind 基础样式给 `img` 加了 `max-width: 100%`，宽度被压回窗口宽，内联的高度没变 | 模板 `src/index.css` 已加 `img, video { max-width: none; }`；放截图用模板的 `BrowserFrame`（按原图比例算宽高）；审图时看截图里的圆形头像是否还是正圆 |

## 音频

| 坑 | 表现 | 解决 |
|---|---|---|
| 开场音乐「怪」 | 从乐句中间开始放 + 合成低频 drone 与曲子调性冲突 | 小节线入场、`build_in` 渐强、删除 drone，爆发前可以只用音效 |
| 改节奏后音效错位 | mix.py 里写死了秒数 | 时间点全部从 `timing.json`（含 `pace`）计算 |
| 听不到声音 | AI 无法主观判断 | 用 `music.py bars`、`mix.py --env` 看曲线；交付时请用户亲耳听 |
| 停顿式曲子看不出来 | 「Island Beat」逐小节能量很均匀，混完 `--env` 才发现每小节后半段接近静音（-79 dB），画面连续时会一顿一顿 | 选曲时再按 0.1 秒窗口统计主段低于 -30 dB 的占比（>3% 就要警惕）；连贯型曲子用滤波做结构：前奏高通渐入、静场低通「闷住」、爆发点全频 |
| 痛点开场配高能 EDM 显得「怪」 | 编程导航第二版：画面在讲痛点，音乐一上来就是夜店感 | 音乐情绪跟叙事走：开场疑惑 / 紧张（稀疏、无鼓、不解决），品牌爆发点再进高能段；有 ElevenLabs 付费账号就按分镜作曲 |
| ElevenLabs 作曲段落时长不准 | 计划写的前奏 4.36 秒，实际 7.6 秒；breakdown 晚了 3 秒 | v2 系列忽略 duration。用 `grid` + `bars` 测真实结构，`musicOffset` 跳过多余前奏，场景边界挪到真实的爆发和 breakdown 上，不够长就在小节线上拼接 |
| ElevenLabs 免费套餐 | 作曲接口 402；音效能用但不能商用 | 先 `elevenlabs.py quota` 看套餐；升级后把免费期生成的素材用同一提示词重新生成 |
| 一次性生成的音效撑不满场景 | 3 个「疑惑前奏」都在 2 秒内衰减到 -60 dB | 需要铺底时用 `--loop` + `continuous, no silence`；每个音效生成后量包络 |
| riser 峰值在开头 | 两次生成的 riser 峰值都在 0.3 秒左右 | 提示词写 `grows steadily and ends exactly at its peak`，生成后确认峰值位置 |
| 并发请求 429 | 免费套餐同时发 5 个请求，第 1 个被拒 | 逐个生成（`elevenlabs.py` 会自动重试） |
| 专业克隆音色不能用 | `voice_not_fine_tuned`：作者本人的专业克隆音色还在训练中 | 先用音色库音色；训练完把 `voice.voiceId` 改回本人，`vo` + `mix` + 换音轨即可，不用重渲染 |
| v4 不能调语速 | `speed`、`style` 对 v4 无效，同一句每次生成的时长也有 ±10% 波动 | 按字数预算写稿；脚本最多自动加速 12%；时间窗 < 2.2 秒的句子和相邻句合并 |
| 旁白被音乐盖住 | 人声 -18 dB、音乐压低 7 dB 时，高能段人声只比音乐高 1~2 dB | 默认 `rmsDb -13`、`duckDb -9`；看 `vo_margin` 每句 ≥ +8 dB |
| 克隆音色咬字不稳 | 作者本人的克隆音色没有 v4 训练，换 multilingual_v2 后 stability 0.5 时多句被转写错 | stability 调到 0.85；`vo --takes 4` 每句多生成几条留最准的；念不清的词直接换说法 |
| 品牌名读错，校验却全过 | 鱼皮 AI 导航：multilingual_v2 把「鱼皮 AI」连读成「pai」，用户听成「鱼排」；网址句转写成「语牌 AI 导航…」，整句相似度 0.90，按 0.85 的门槛算通过 | 品牌名、网址写进 `voice.keywords`，少一个就判 `CHECK_WORD`；加逗号、引号、拆字母都救不了 multilingual_v2，换 `eleven_v3` + `sts` |
| 修好读音，音色却变了 | 换成 eleven_v3 后读音全对，用户说「现在的声音和我的不太一样了」：这个克隆音色只训练了 v2 系列，v3 用的是近似音色 | `voice.sts: true`：v3 读准后用已训练的 `eleven_multilingual_sts_v2` 转回本人音色；换模型前先出 3 句试听 |
| 转音色把短词读糊 | 「试试鱼皮 AI 导航！」v3 原声转写正确，转成本人音色后 4 条都成了「设置 / 这是 / 就是鱼皮 AI 导航」 | `vo` 的多条择优已改为在转音色之后挑；句首加引导字、品牌名前加逗号：「快来试试，鱼皮 AI 导航！」一次通过 |
| 人物有回音 | multilingual_v2 上克隆音色每句句尾混响拖尾 90~360 ms，压在音乐下像回音；想用 Audio Isolation 去掉，单句不足 4.6 秒直接 400 | `vo` 自动量 `tail_ms`，> 250 ms 判 `ECHO`；换 v3 + `sts` 后 20~110 ms |
| Q 版画风配了儿歌 | 鱼皮 AI 导航第一版选了童趣的「Kids」，第二版换成轻快流行，两次都被否 | 配乐跟受众和产品走（学 AI 的大学生和职场人 → 明亮励志、有起伏）；被否两次就拉开曲风出 5~6 首叠旁白的试听让用户挑 |
| 把转写误差当成混音问题 | 面试鸭「再精挑」被听成「带金条」，当时以为是 riser 盖住人声，删了音效还写进了文档；事后对照（同一段加不加 riser 各转写 3 次）全都对，真正起作用的是同时换了一条更清楚的录音 | `check-mix` 已自动截段复查两次；确实没听清先重新生成那一句；怀疑音效或混音时先做改前 / 改后对照转写，有证据了再改、再写进文档 |
| `check-mix` 误报 | Scribe 在转写里插「[动感的背景音乐]」；句中错一个同音字就判整句没听见 | 已修复：比对前去掉方括号标注，逐句改用滑动窗口相似度 ≥ 0.8 |
| 改版时项目脚本是旧的 | 面试鸭复制 template 后，template 又加了旁白压音乐、`check-mix`、网页版音频时钟；改版时项目里全都没有，`mix.py` 还是上一版的分镜 | 改版、续做旧项目先跑 `python3 scripts/sync_template.py`；场景重排后 `mix.py` 按新分镜重写 |
| template 里混进生成文件 | 在 template 里试跑 `mix.py`，`public/audio/mix.wav` 和 `audio-src/_mix_raw.wav` 留在了 template，会被复制进每个新项目 | 不要在 template 里跑生成命令；要试就 `cp -R template /tmp/x` 后在副本里跑 |
| 单独听清，混进去听不清 | 网址单独转写是「codefather.cn」，成品混音里成了「点 CM」 | `check-mix` 转写成品混音；关键句单独 `duckDb: -14`、减弱同时刻的高频音效、`say` 用大写字母「C N」 |
| 克隆音色音调怪 | 作者本人的克隆音色全片配完，用户说「很多音调都有点怪」；转写还频繁出错（「路由→绿油」「五点五→无电雾」「十月→日月」） | 克隆音色和 2 个音色库音色一起试听，让用户选；Fable 一片换成 Haoran（v4）后混音转写 1.000 |
| 听错会改变事实的词 | 「Fable 5.5 一上线」被转写成「已上线」；「五点五一正式发布」被转写成「5.51」 | 这类不是同音字问题，必须改稿：「等它正式发布」；数字后面不接「一 / 已」 |
| 作曲没给计划里的安静段 | 计划写了 interlude（只有钟表声），两版生成都是满能量 | `audiolib.muffle` 低通闷住那几小节，结束时恢复全频接重击 |
| 自己写的切静音把整句静音了 | `afade=t=out:st=0` 让淡出从第 0 秒开始；时长看着正常，转写结果是「空白音频」 | 已修复；生成后一定要转写，时长正常不代表有声音 |

## 工程与渲染

| 坑 | 表现 | 解决 |
|---|---|---|
| 4K 渲染图片解码失败 | 日志 32 次 `EncodingError: The source image cannot be decoded`，但渲染显示成功 | 同屏大量大图时，为该场景单独准备缩小版（显示宽度 ×2 即可），`--concurrency` 降到 6 |
| 时长乘帧率有浮点误差 | `78.4 * 60 = 4704.000000000001` | `Math.round(timing.duration * fps)`（模板已处理） |
| `npm install` 报 ERESOLVE（@types/react-dom 19.3 要求 @types/react ^19.3） | 模板 lock 里缺 `@types/react-dom`，`^19.2.0` 拉到了新版 | 模板已固定 `"@types/react-dom": "19.2.3"` 并更新 lock；以后新增依赖一律写死版本 |
| `legacy-peer-deps` 装坏依赖 | 打包时 `Cannot find module 'ajv/dist/compile/codegen'` | 不要用 legacy-peer-deps；模板已锁定兼容版本（vite 6 + @vitejs/plugin-react 4），用模板自带的 package-lock |
| `prefetch is not a function` | 从 `@remotion/preload` 导入 | 从 `remotion` 导入 `prefetch` |
| 网页版旁白「两个人在说、全程回音」 | `@remotion/media` 的 `<Audio>` 用 Web Audio 分块播放，浏览器跑不满帧时反复重新同步，旧的音频块还在播又排进新的一批：4 秒里启动了 1948 个 43 ms 的块（正常约 94 个），同一时刻叠着约 6 份 | 网页版不让 Player 管声音（`withAudio: false`），由一个普通 `<audio>` 当时钟，每帧把 Player `seekTo` 到对应帧，画面跟不上就丢帧（模板 `web/App.tsx` 已处理）。中间试过把 Player 里的声音换成 `<Html5Audio>`：不再叠加了，但 Player 每 2 秒把声音往回拉 0.7 秒等画面，最后半句被重播，听起来还是「两遍回音」。验证：在真实 Chrome 里播放 10 秒，`<audio>.currentTime` 每秒涨 1.0、从不倒退，`AudioBufferSourceNode.start` 计数为 0。测完关掉测试页，不然测试页的声音会和用户正在听的叠在一起 |
| 网页版「并没有声音」 | 鱼皮 AI 导航：在 Cursor 内置浏览器里点播放，画面在走，3 秒内一段音频都没送出；同一页面在 Chromium 里正常出声。另外用 `python3 -m http.server` 起的服务不支持 Range 请求，音频不能按需读取 | `npm run web:build && npm run web:serve`（http-server，支持 Range），用系统浏览器打开 `http://127.0.0.1:18765`；内置浏览器只用来看画面 |
| 用户在内置浏览器里登录，截图却只能 1 倍 | 内置浏览器模拟 2 倍像素密度时截图平铺错位，独立打开的 Chrome 又没有登录状态 | 优先请用户在 `shot.py --login` 弹出的窗口里再登录一次；不方便时用 `scripts/snapshot.js` 在已登录页面里导出自包含 HTML，`scripts/snapshot.py` 在本地按 1920×1080 @2x 重渲染（见 `素材获取.md`） |
| 渲染中途改了混音 | 4K 渲染要读 `public/audio/mix.wav`（结尾合成音轨时也会读），渲染期间重新混音可能读到写了一半的文件 | 渲染期间把新混音写到别处（`Mix.master(dest="out/mix-vo.wav")`），渲染完再覆盖，或直接用 ffmpeg 把新音轨换进成片 |
| `curl` 下载 X 图片全部静默失败 | `pbs.twimg.com` 被重置连接，`curl` 不读 macOS 系统代理，`check=False` 吞掉了错误，只剩 `meta.json` | 用 `xgrab.py`（自动读系统代理、失败会打印）；自己写时 `scutil --proxy` 查端口再 `-x` |
| ElevenLabs 偶发 `Connection reset by peer` | 连续生成 8 个音效时一半失败，重试循环用 `tail` 判断成功导致没重试 | `elevenlabs.py` 已对网络错误自动重试；自己写重试时用「目标文件存在」判断成功 |
