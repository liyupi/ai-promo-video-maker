# 校验清单

校验由 AI 自主完成，发现问题 → 修 → 重新截图复核，全部通过才交付。

## A. 自动闸门（必须 0 ERROR）

```bash
npm run fonts                 # 报告缺字 → 换字体或改文案
python3 scripts/elevenlabs.py vo    # 有旁白时：每句 OK（时长装得下 + 转写一致）
npm run mix                   # 混音；有旁白时打印 vo_margin，每句人声须 ≥ +8 dB
python3 scripts/elevenlabs.py check-mix   # 有旁白时：转写成品混音，整体匹配 ≥ 0.97、每句都听得清
npm run check:assets          # 缺文件 / 图片过小过大 / 缺字体
npm run lint                  # eslint + tsc
```

成片后：

```bash
python3 scripts/check_video.py out/final-4k.mp4 --scale 2   # 规格、日志报错、响度、按场景抽帧
```

渲染日志里只要出现 `cannot be decoded` 之类的报错，哪怕渲染「成功」了，也要当失败处理（见踩坑记录）。

## B. 审图（每轮都做）

```bash
node scripts/stills.mjs --scenes && python3 scripts/sheet.py   # 每个场景 35% / 85% 两帧
node scripts/stills.mjs 11.4 11.6 18.7                          # 关键过渡、爆发点、文字出齐时刻补截
```

打开 `out/sheet.jpg`，可疑的单张用原图（`out/stills/*.jpg`）放大看。用 pi 时直接 `read out/sheet.jpg`，可疑的单张再 `read out/stills/<名字>.jpg`。逐条确认：

**文字**
- [ ] 所有文字与背景对比足够：浅色背景上的浅色渐变字、光效中心的白字、和背景同色系的字都要改（加深颜色、加描边光晕、压暗背景）。
- [ ] 没有溢出、截断、意外换行；中文标题不在词中间断行（「五大核心心 / 法」这种要改布局或字号）。
- [ ] 被遮挡的文字：卡片叠放时后面卡片的字是否被压住。
- [ ] 数字、名称、网址全部正确，和调研笔记一致。
- [ ] 自己写的每条说明（「纯 SVG」「带配乐」「七种画风」「最近才火」这类定语）都能在原帖 / 官方页里找到原话；找不到就删掉。
- [ ] 视频画面上的文字（尤其是快切蒙太奇，画面忽明忽暗）都有深色底条，不只靠文字阴影。

**故事**（对照 AGENTS.md 第 4 条原则）
- [ ] 外行复述测试：只读 `timing.json` 的旁白稿，按顺序写出 5 句话的「来龙去脉」。哪句接不上上一句、哪个词需要背景知识才懂，就改那句或补一张解释卡。
- [ ] 第一句旁白和第一屏大字，单独拿出来也能说明「这是什么、发生了什么」。
- [ ] 字和声音说的是同一件事：屏幕大字最多比旁白早 1.5 秒出现，不能晚于旁白。

**节奏**（对照 AGENTS.md 的「节奏：底线 + 密度」）
- [ ] 每段文字的停留时间够读完；重点展示 ≥ 1.3 秒，快切 ≥ 0.65 秒，信息场景 ≥ 3.5 秒。
- [ ] 网址/CTA 在最高潮出现并停留 ≥ 3 秒。
- [ ] 第 3 秒的截图里已经有痛点或核心亮点；第 5 秒前出现第一个高能点。
- [ ] 开头 0~12 秒按 0.5 秒间隔抽帧看一遍：前 4 秒不超过 2 个画面；推镜里每个焦点、每行字都停够 1.4 秒（Fable 第二版开头 4 秒 3 个镜头、2 秒里塞两个焦点，被评「太快，来不及看画面」）。
- [ ] 按 1 秒间隔抽帧（`node scripts/stills.mjs` 传入 0,1,2,…），逐段检查：不存在连续 2 秒以上「画面没有新信息」的片段；纯转场 ≤ 0.6 秒。
- [ ] 把所有场景截图排在一起看：同一版式没有连续出现 3 次。
- [ ] 总时长在需求确认的范围内（默认 45~60 秒）。

**真实素材**
- [ ] 每个功能段落都有真实界面截图或真实作品图，全片不少于 8 张；有一段 ≥ 8 张的真实作品快切。
- [ ] 真实截图在 4K 下清晰（源图宽 ≥ 显示宽度 × 2）；截图里没有活动横幅、悬浮条、个人隐私信息（右上角账号头像、用户名）。
- [ ] 截图没有被压扁或拉长：每个放截图的场景挑一帧，看截图里的圆形头像、logo、图标是否还是正圆，文字字形是否比原图窄。放大、平移截图的场景重点看（鱼皮 AI 导航旧模板全片截图被压窄 1.12~1.3 倍）。

**画面**
- [ ] 截图素材清晰（4K 下不糊）、裁切位置合适（主体没被裁掉）。
- [ ] 展示的作品/功能都确实属于这个产品，没有重复（同一作品不出现两张相似截图）。
- [ ] 每个场景有持续微运动，没有死帧；转场前后不黑屏、不闪错帧。
- [ ] 风格与需求确认一致，没有滑回「默认的深色科技风」。

**网页版**（有的话）
- [ ] `npm run web` 打开，海报帧、加载进度、播放、暂停、结束画面、CTA 按钮都正常；播放中画面上没有多余控件遮挡。
- [ ] 声音连续、只有一份：在 **真实 Chrome**（Playwright 或 DevTools MCP）里点播放，每 0.25 秒读一次 `<audio>.currentTime`，10 秒内应每秒涨 1.0、从不倒退；hook `AudioBufferSourceNode.prototype.start` 计数为 0。AI 工具的内置浏览器比真实 Chrome 慢，结果只能参考。
- [ ] 测完立刻暂停并关闭测试页（测试用的 Chrome 和内置浏览器都要关）：它们的声音会从用户的扬声器放出来，和用户正在听的叠在一起。
- [ ] 给用户看网页版时用 `npm run web:serve`（支持分段读取音频），再在**系统浏览器**里打开 `http://127.0.0.1:18765`（macOS `open`、Windows `start`、Linux `xdg-open`）。不要用 `python3 -m http.server`（不支持 Range 请求），也不要让用户在 AI 工具的内置浏览器里听：鱼皮 AI 导航的网页版在内置浏览器里点播放后一段声音都没送出，用户反馈「并没有声音啊」，同一页面在 Chrome 里正常。
- [ ] 结束后停在最后一帧（`moveToBeginningWhenEnded={false}`），CTA 不和片尾画面里的文字重叠。

**声音**
- [ ] `python3 scripts/mix.py --env` 曲线符合设计：入场点、渐强、爆发跳变、骤停、结尾衰减。
- [ ] 音效时间点与画面事件一致（抽 2~3 处，用截图时间和 cue 时间对照）。
- [ ] `vo` 全部 `OK`、`check-mix` 通过，而且 `voice.keywords` 里列了品牌名和网址（整句相似度会放过品牌名读错，见 `配音.md` 第 3 节）。
- [ ] 改过旁白的模型、音色设置或开关了 `sts`：已经给用户出过 3 句试听并得到确认。
- [ ] 旁白说的和画面对得上：点名的项目、数字在那一刻确实在屏幕上（用 Scribe 逐词时间戳核对关键词，比如网址要在网址上屏之后才念出）。
- [ ] 开场的音乐情绪和画面一致（痛点段是疑惑 / 紧张，不是一上来就高能）。
